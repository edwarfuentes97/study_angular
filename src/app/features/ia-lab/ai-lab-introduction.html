IA para Ingeniería de Software

Esta ruta está pensada para que aprendas lo esencial de forma práctica: conceptos, ejemplos reutilizables y un laboratorio que te permita avanzar de verdad.

Conceptos

  • LLM: modelo de lenguaje capaz de entender texto, responder preguntas y ayudar con código.
  • Modelos locales: se ejecutan en tu máquina y te dan más control, privacidad y aprendizaje práctico.
  • Prompts: la forma en que defines contexto, objetivo, formato y restricciones.
  • Tokens y contexto: afectan la cantidad de información que el modelo puede manejar.
  • Structured outputs: pedir JSON estricto para integrar IA con apps reales.
  • Embeddings y RAG: permitir que el modelo responda usando tus documentos y datos propios.
  • Tools y agentes: dar capacidad al modelo para ejecutar acciones y resolver tareas en pasos.

Ejemplos

  • Ejemplo 1: prompt simple para resumir un texto en 3 puntos.
  • Ejemplo 2: pedir un JSON con una estructura clara para extraer gastos o categorías.
  • Ejemplo 3: usar una herramienta como buscarDocumento() o guardarRegistro() dentro de un flujo de agente.
  • Ejemplo 4: un flujo básico de RAG donde el modelo responde usando un conjunto de documentos.

Plantilla de ejemplo útil

System: Eres un asistente técnico.
User: Resume este texto en 3 puntos.
Output: JSON con tres elementos.

Laboratorio

  • Lab 1: instala un modelo local y comprueba que responde a un prompt simple.
  • Lab 2: diseña un prompt que devuelva una salida estructurada en JSON.
  • Lab 3: crea una mini app que envíe un prompt y muestre la respuesta.
  • Lab 4: añade una herramienta o una función al flujo y observa cómo cambia la respuesta.
  • Lab 5: construye un pequeño agente que complete una tarea en varios pasos.
