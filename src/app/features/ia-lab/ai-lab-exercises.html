🧪 Laboratorio IA

Aquí tienes un camino práctico para aprender haciendo. Cada reto está pensado para ser ejecutable y útil.

1️⃣ Lab: modelo local

Instala un modelo local con Ollama o LM Studio y comprueba que responde a un prompt básico.

✅ Entregables

  • Captura la respuesta del modelo.
  • Prueba al menos dos valores de temperatura.
  • Resume qué cambió en la salida.

2️⃣ Lab: prompt estructurado

Diseña un prompt que pida una salida en formato JSON con campos claros y un objetivo concreto.

✅ Entregables

  • El modelo devuelve JSON válido.
  • Incluyes contexto y restricciones.
  • El resultado es reutilizable en una app.

3️⃣ Lab: app simple con IA

Construye una mini interfaz donde el usuario escriba un prompt y reciba una respuesta del modelo.

✅ Entregables

  • Hay un formulario simple.
  • Se muestra el estado de carga.
  • Se manejan errores de forma clara.

4️⃣ Lab: herramienta o tool

Agrega una función o herramienta al flujo y observa cómo el modelo puede usarla para completar una tarea.

✅ Entregables

  • Usas al menos una herramienta.
  • El modelo toma una decisión basada en la salida.
  • La tarea se completa en varios pasos.

5️⃣ Lab: agente simple

Diseña un agente que siga un objetivo concreto, use herramientas y termine con una respuesta accionable.

✅ Entregables

  • El agente tiene un objetivo claro.
  • Usa contexto o memoria mínima.
  • Produce un resultado final útil.
